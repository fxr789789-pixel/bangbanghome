# 帮帮正式开发路线

## 当前已落地

- 移动端 App 主界面：`首页 / 需求 / 师傅 / 订单 / 我的`
- AI 发布需求演示
- 需求大厅分类导航和筛选
- 师傅分类导航、师傅主页、评价和技能证明展示
- 首次接单资料、技能认证、专业资质限制
- 实名认证流程：实名信息填写 -> 人脸识别
- 订单聊天、支付、退款售后、举报投诉、安全中心、后台审核演示
- Supabase client、类型定义、市场数据读取和 mock 回退
- Supabase PostgreSQL 初始迁移 SQL

## 服务分类与资质规则

普通服务默认人人可接，技能证明选填，客户下单前可查看。

专业或高风险服务必须资质认证通过后才能接单：

- 开锁、换锁、智能门锁安装
- 电工维修
- 燃气维修
- 医疗护理
- 高空作业
- 专业家电维修
- 专业私教

生活陪伴类允许合规服务：

- 陪聊天
- 陪散步
- 陪购物
- 陪老人聊天
- 线上娱乐陪伴

平台必须禁止违法、色情、骚扰、灰产和侵犯隐私类服务。

## 下一阶段开发

1. Auth：接入 Supabase 登录注册、会话状态、手机号/验证码方案。
2. Profiles：真实用户资料、实名状态、师傅状态。
3. Requests：发布需求写入数据库、需求大厅读取真实数据。
4. Services：师傅技能、技能证明、资质证明上传和审核。
5. Orders：接单、下单、订单状态流转。
6. Storage：头像、形象照、需求图片、评价图片、资质证书。
7. Realtime：订单聊天、系统通知。
8. Admin：实名审核、资质审核、举报投诉、财务和订单纠纷。
9. 官网：下载页、隐私政策、服务协议、PWA 安装入口。
