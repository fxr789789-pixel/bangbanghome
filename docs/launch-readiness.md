# 帮帮上线准备清单

本文档用于区分“可公开预览”和“可正式运营”。当前项目已经可以作为预生产 MVP 部署到 Vercel，但真实交易上线前还需要完成第三方服务、合规材料和生产数据闭环。

## 当前已完成

- 移动端优先 UI：开屏页、首页、需求大厅、师傅大厅、订单中心、个人中心。
- 首页轮播、热门服务折叠、AI 智能分类入口、师傅资料页、评价与资质展示 UI。
- 首次注册实名认证流程 UI：填写实名信息 -> 人脸识别 -> 通过。
- 人人可接单的技能认证 UI，专业类服务预留资质审核。
- Supabase 项目已创建核心业务表、Storage bucket、索引和 RLS。
- Vercel 生产部署已完成，正式访问地址为 `https://bangbanghome.vercel.app`。

## 不能直接运营的模块

这些模块当前仍是 UI 或接口预留，不能作为真实业务闭环使用：

- 手机号短信登录和验证码校验。
- 真实姓名、身份证、人脸识别核验。
- 需求发布、师傅接单、订单状态的真实入库和权限校验。
- 图片上传、资质材料上传、聊天图片上传。
- 微信/支付宝支付、退款、分账、佣金结算。
- 后台审核、举报投诉、客服工单、风控封禁。
- 用户协议、隐私政策、平台服务规则的正式法律文本。
- 内容安全审核和违法违规服务拦截。

## 你需要准备

- 生产域名：建议准备独立域名，例如 `bangbang.xxx`。
- 备案材料：如果面向中国大陆用户且使用大陆服务器/域名解析，需准备 ICP 备案；如上架应用商店，还需按平台要求准备材料。
- Supabase 生产项目：当前项目可继续用，也可以新建 production 项目。
- 短信服务：阿里云短信、腾讯云短信或其他合规短信服务。
- 实名/人脸供应商：腾讯云慧眼、阿里云实人认证、百度智能云实名认证等。
- 支付商户：微信支付商户号、支付宝开放平台应用、结算银行卡、平台服务费规则。
- 对公主体：营业执照、法人信息、客服联系方式、平台协议主体。
- 客服与风控：投诉处理流程、退款规则、禁售服务清单、人工审核人员。
- 应用分发材料：App 名称、图标、截图、隐私政策链接、权限说明。

## 技术上线阶段

1. 账号登录
   - 接入 Supabase Auth。
   - 配置短信 OTP 或第三方短信网关。
   - 创建登录、退出、会话刷新和用户资料初始化流程。

2. 实名认证
   - 新增 `identity_verifications` 表。
   - 接入第三方实名和人脸核验 API。
   - 存储核验流水号和审核状态，不在前端展示完整证件号。

3. 需求和接单
   - 发布需求写入 `requests`。
   - 师傅技能写入 `services` 或技能认证表。
   - 接单生成 `orders`，并限制只有合格师傅可接专业订单。

4. 上传与隐私
   - 头像、人脸照、需求图片、资质图片上传到 Supabase Storage。
   - 私有 bucket 使用签名 URL，公开头像单独处理。
   - 对身份证、人脸照、资质证明设置严格访问策略。

5. 支付和退款
   - 创建支付单、回调验签、订单状态变更。
   - 支持退款申请、售后审核、退款回调。
   - 平台服务费、推广佣金、师傅收入分账独立记录。

6. 后台管理
   - 管理员登录与角色权限。
   - 实名审核、资质审核、需求审核、举报投诉、订单纠纷。
   - 财务流水、提现审核、内容安全记录。

7. 发布上线
   - Vercel Production 环境变量完整配置。
   - Supabase RLS Advisor 和 Performance Advisor 检查通过。
   - 生产域名、HTTPS、隐私政策和用户协议链接可访问。
   - 发布前完成移动端主流程验收。

## 上线判定

- 预览上线：当前版本已达到。
- 小范围内测：完成登录、真实发布需求、真实接单、订单入库后可进行。
- 正式运营：必须完成实名、人脸、支付、退款、后台审核、协议合规和客服风控。
