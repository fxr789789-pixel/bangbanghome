# Dry-Run Report

更新时间：2026-07-14

## 目的

本文件用于记录“准备发送但尚未真实发送”的融资外联演练结果。

## 当前公开仓库策略

由于当前仓库是 `Public`，本文件不记录真实机构名称、真实邮箱、真实发送内容，只记录流程是否可运行、字段是否齐全、风控规则是否生效。

## Dry-Run Checklist

- [ ] 发件配置已加载
- [ ] 去重规则已生效
- [ ] 仅选取公开邮箱或官方表单
- [ ] 自动回复关闭
- [ ] 自动跟进关闭
- [ ] 发送上限已生效
- [ ] 日报模板可生成
- [ ] CRM 字段结构完整

## 示例输出（去敏）

- 候选机构数量：`0-50`
- 可安全发送数量：`0-10 / batch`
- 表单类机构数量：`0-20`
- 因重复或非公开入口被拦截数量：`0-n`
- 是否发生凭据错误：`yes/no`
- 是否发生附件缺失：`yes/no`

## 备注

真实 dry-run 结果应记录在私有存储中，不应提交到 Public 仓库。
