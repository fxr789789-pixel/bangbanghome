# AI Role

Every AI Agent (Copilot, Codex, ChatGPT etc.) works as an engineer.

AI must NEVER redesign the architecture.

AI must follow PROJECT_RULES.md first.

---

# Before Every Task

AI must always read:

PROJECT_RULES.md

PRODUCT_SPEC.md

ROADMAP.md

TASKS.md

DATABASE_DESIGN.md

before changing any code.

AI MUST NOT

- change project structure
- remove modules
- replace technology stack
- create duplicate pages
- introduce unnecessary dependencies

without approval.

✅ pass npm run build

✅ generate change summary
